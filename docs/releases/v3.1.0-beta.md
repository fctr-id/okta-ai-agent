# "Catch of the Day"

**Tako v3.1.0-beta — Recommended upgrade for all Tako users.**

This release brings Tako to Microsoft Teams, adds continued conversations to Slack, and improves the web experience with clearer conversation cards and interactive result tables. It also fixes issues that could cause incomplete sync data, repeated API calls, and misleading error states.

## ✨ Highlights

- **Microsoft Teams bot:** Ask questions in a personal Teams chat, refine results with follow-ups, answer clarification questions, and download retrieved results as CSV. Includes a ten-row preview, New Query action, Entra group access controls, and an uploadable app package builder.
- **Continued conversations in Slack:** Reply in a result thread to build on previous results. New Query starts a fresh thread; Download CSV exports saved results without rerunning the query.
- **Refreshed web experience:** Collapsible conversation cards keep questions, activity, execution details, and results together. Updated navigation, sync controls, and expandable long values make the interface easier to use.
- **Multi-column sorting and grouping:** Sort results by multiple columns with numbered priorities, or group rows into collapsible sections with counts that update as you search. Previews remain clearly labeled.
- **Optional AI reasoning:** Control supported models with the shared `AI_REASONING_EFFORT` setting. The sample uses `high`; `none` or an unset value leaves reasoning behavior to the model's defaults.
- **Better follow-ups and clarification:** Saved-data analyses can return results directly without another generated script. Clarification questions appear as normal conversation turns, and timezone-aware requests use browser context and daylight-saving-aware conversions.

## 🔧 Optimizations and fixes

- **More reliable sync:** Reused connections, fewer database lookups, and bounded batch commits while retaining progress updates. Pagination failures, exhausted retries, and cancellation no longer appear as successful retrievals before stale-record cleanup.
- **Safer database updates:** Fixed relationship cleanup and device-batch rollback so incomplete retrievals do not silently erase saved links. Sync failures remain visible alongside the last successful sync information.
- **More reliable agent execution:** Fixed duplicate API test execution, helper-function scope errors, escaped-string handling, and tool-budget exhaustion. Improved guidance for reusing evidence and avoiding repeated lookups.
- **More complete API results:** Fixed normalization that could discard resource fields containing nested arrays. Valid helper functions are no longer rejected solely because their names contain words such as "execute" or "input"; safety checks still apply.
- **Azure OpenAI compatibility:** Updated Azure v1 Responses API configuration and endpoint handling, using deployment names without a dated API version.
- **Session security and cleanup:** Removed shared default signing keys and insecure fallbacks. Bot sessions can survive restarts when storage is preserved; expired local session data is cleaned up automatically after 24 hours of inactivity by default.
- **Diagnostics and dependencies:** Improved persistent logs, user-facing errors, and CLI failure reporting. Major dependency updates include Pydantic AI 1.107.6 and cryptography 50.0.1.

## 📌 Upgrade notes

- **Login sessions:** Without a configured `JWT_SECRET_KEY`, restarts require a fresh login. Multiple workers or replicas need the same configured key. Explicit custom keys must be at least 32 bytes. Accounts, saved conversations, and synced data are preserved.
- **Reasoning:** `high` can increase latency and cost. Use `none` or remove the variable if your model does not support the setting; this does not disable models that reason by default.
- **Azure:** Use an endpoint ending in `/openai/v1/` and configure Azure deployment names. `AZURE_OPENAI_VERSION` is no longer required.
- **Slack:** Existing apps need the updated message subscriptions and permissions for follow-ups and buttons. Follow the [Slack setup guide](https://github.com/fctr-id/okta-ai-agent/wiki/Tako-AI-%E2%80%90-Slack-Bot-Setup-%26-Testing-Guide).
- **Teams:** Enable the optional integration and follow the [Teams setup guide](https://github.com/fctr-id/okta-ai-agent/wiki/Tako-AI-%E2%80%90-Teams-Bot-Setup). CSV delivery in personal chats uses Teams' file-consent flow.
